Beyond model pricing

Good AI governance includes cost governance.

Measure what matters

Track cost per useful output.
Cost per approved brief, published article, accepted image or successful agent task is more useful than tokens alone.
Monitor quality and rework.
Extra drafts, retries, longer context and failed executions can materially change usage.
Set ownership and limits.
Assign a budget owner, usage alerts, approval thresholds and clear escalation paths.

Costs not included here

Copilot or Copilot Studio licences and credits, platform capacity, connectors, retrieval and embeddings, document extraction, infrastructure, orchestration, monitoring, human review, support, taxes and exchange-rate effects.

Provider-specific multimodal pricing, cached tokens, batch discounts and bundled capacity can change the result. Avoid double counting charges already included in a platform subscription.

For a business case, validate these assumptions with measured usage and current provider-specific pricing before committing to a budget.

How the estimate works

We estimate activity volume first. Each marketing brief, blog post, image request or agent execution has a hypothetical average input and output token allowance. Those allowances include typical prompting and context for the activity, but real use varies by model, source material, language, tools and revisions.

Active employees = employees with AI access × active usage percentage

Content volume = active employees × monthly outputs per active employee

Agent executions = deployed agents × monthly executions per agent

Input / output tokens = sum of activity volume × corresponding tokens per activity

Model cost = input tokens ÷ 1,000,000 × input rate + output tokens ÷ 1,000,000 × output rate

Total variable cost = model cost + finished images × image charge

Pages are an approachable way to think about business outputs, but page count is not an exact token measure. The calculator allows the assumed page length to be adjusted, which scales text-output tokens; source context and agent processing are estimated separately.
